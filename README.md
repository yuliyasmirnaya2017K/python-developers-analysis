# Комплексний аналіз даних опитування Stack Overflow за допомогою Pandas

## Мета проєкту
Дослідження глобального датасету Stack Overflow Developer Survey. Проєкт спрямований на розрахунок базових метрик обсягу даних, аналіз повноти відповідей, вивчення центральних тенденцій досвіду роботи, оцінку популярності мови Python, а також географічний та освітній аналіз фінансової компенсації спеціалістів.

## Інструменти та методи аналізу (Pandas Stack)
* **Завантаження та первинний аналіз:** Робота з великими DataFrame, контроль цілісності структури при завантаженні даних та схем (`survey_results_schema`).
* **Обробка пустих значень та множин:** Використання методів роботи з пропущеніми значеннями (Missing Data), робота з типами `set` та реалізація інтерсекції (перетину) множин для точної фільтрації колонок.
* **Описова статистика:** Розрахунок мір центральної тенденції (`mean`, `median`, `mode`) з урахуванням специфіки пропущених значень у числовому полі `WorkExp`.
* **Робота з категоріальними та текстовими даними:** Фільтрація рядків, підрахунок частот, аналіз складних множинних відповідей у текстових полях за допомогою `.str.contains()`.
* **Групування та багатовимірна агрегація:** Складне групування даних за допомогою `.groupby()` та агрегаційних функцій `.agg()` для розрахунку регіональних метрик.
* **Сортування та вибірка:** Ранжування великих масивів за допомогою `.sort_values()` та виділення Топ-N записів.

## Структура виконаних завдань та покриття кейсу
Проєкт успішно реалізує всі вимоги ментора і розділений на 9 аналітичних блоків:

1. **Підрахунок загальної кількості респондентів:** Визначено точний обсяг вибірки датасету Stack Overflow через коректні методи підрахунку записів.
2. **Аналіз повноти відповідей респондентів:** Завантажено файл схеми, отримано унікальні імена питань `qname`, реалізовано перетин множин для виділення цільових колонок та підраховано кількість респондентів без жодного пропуску.
3. **Статистичний аналіз досвіду респондентів:** Обчислено середнє, медіану та моду для колонки досвіду роботи `WorkExp` з коректним оброком NaN-значень.
4. **Аналіз віддаленої роботи:** Ідентифіковано формат роботи та розраховано точну кількість remote-фахівців.
5. **Визначення популярності Python:** Реалізовано пошук підрядка у полі множинних відповідей та розраховано частку Python-розробників у відсотковому форматі.
6. **Аналіз шляхів навчання програмуванню:** Відфільтровано та підраховано респондентів, що здобували освіту через онлайн-курси, враховуючи множинні варіанти відповідей.
7. **Географічний аналіз компенсації Python-розробників:** Проведено групування за країнами (`Country`) та розраховано середню і медіанну річну компенсацію (`ConvertedCompYearly`) у вигляді фінального зведеного DataFrame.
8. **Аналіз освіти найбільш оплачуваних спеціалістов:** Виконано сортування за спаданням доходу, відібрано Топ-5 респондентів та виведено їхні рівні освіти.
9. **Аналіз популярності Python за віковими категоріями (Зіркове завдання):** Проведено групування за віком з розрахунком відсотка використання Python всередині кожної вікової групи.
